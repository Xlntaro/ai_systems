# Картки з конспекту

CLI перетворює нотатки на короткі картки для повторення. Він приймає текст українською або англійською й показує запитання та відповіді українською. Запити йдуть до локального Ollama через `/v1/chat/completions`.

## Запуск на NixOS

З кореня репозиторію в першому терміналі запусти сервер.

```bash
nix --extra-experimental-features 'nix-command flakes' develop path:.
lab4-serve
```

У другому терміналі відкрий той самий dev shell і завантаж модель.

```bash
nix --extra-experimental-features 'nix-command flakes' develop path:.
ollama pull qwen2.5:1.5b-instruct-q4_K_M
printf '%s\n' 'TTFT — час до першого токена. RAM — оперативна пам’ять.' |
  python3 lab4/app/main.py
```

Можна передати файл UTF-8, змінити локальну модель або попросити машинозчитуваний вивід.

```bash
python3 lab4/app/main.py notes.txt --json
python3 lab4/app/main.py notes.txt --model qwen2.5:3b-instruct-q4_K_M
```

Без Nix потрібні Python 3.10+ і локальний Ollama. Запусти Ollama з `OLLAMA_CONTEXT_LENGTH=4096` на `127.0.0.1:11434`, завантаж модель командою вище і виконай той самий Python-скрипт. Застосунок використовує стандартну бібліотеку Python.

## Параметри

- `temperature=0.1` зменшує варіативність формулювань і структури.
- `seed=1` задає однаковий початковий стан семплінгу під час повторних перевірок.
- `max_tokens=384` обмежує генерацію коротким набором із максимум чотирьох карток.
- Контекст **4096 токенів** задає сервер. Конспект обмежено **3000 байтами UTF-8**, щоб у контексті лишилося місце для інструкції та відповіді.
- Під час запиту CLI показує «Генерую картки…». Таймаут запиту становить **60 секунд**. Відповідь перевіряється на валідний JSON і наявність непорожніх запитання й відповіді для кожної картки.
- Якщо в полі запитання модель повернула твердження з конспекту дослівно, CLI робить із нього картку з пропуском. Інші твердження в цьому полі відкидаються.

## Матеріали перевірки

Промпти й критерії містить [quality_cases.json](quality_cases.json), а відповіді та оцінки обох моделей — [quality_results.json](quality_results.json). За повним виконанням критеріїв 1.5B отримала 7/10, 3B — 2/10. Числа й одиниці у згенерованих картках варто звіряти з нотатками.
